# 🧪 Part 1 Practice Sandbox

This directory contains my experimental code and notes from the Fullstack Open Part 1 reading materials. Instead of a polished application, this is a collection of isolated files and components used to test specific React and JavaScript behaviors.

## 📚 Concepts Explored

### 1a: Introduction to React

- **JSX Syntax:** Experimented with embedding dynamic JavaScript expressions directly into HTML structures.
- **Component Architecture:** Practiced building standard arrow-function components and rendering them within a root `<App />`.

### 1b: JavaScript Deep Dive

- **Functional Programming:** Transitioning from traditional `for` loops to using array methods like `.map()` and `.filter()`.
- **Object Destructuring:** Extracting properties directly from objects to clean up component props.
- **The `this` Keyword:** Noted the critical difference between Java's predictable `this` and JavaScript's dynamic `this` (and how `.bind()` or Arrow Functions fix it).

### 1c: Component State & Event Handlers

- **The `useState` Hook:** Initializing and updating basic state (numbers, strings).
- **Event Handling:** Wiring up `onClick` events.
- **State Asynchronicity:** Observing how React batches state updates and delays re-renders.

### 1d: Complex State & Debugging

- **Immutability:** Learning the golden rule of React state—never mutate arrays or objects directly. Practiced using the spread operator (`...`) to create shallow copies.
- **Conditional Rendering:** Using `if` statements and ternary operators to show/hide UI elements based on state.
- **Debugging:** Getting comfortable with the React Developer Tools extension and strategic `console.log()` placements.
