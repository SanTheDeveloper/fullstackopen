# Part 1: Fundamentals of React ⚛️

This section marks the beginning of my deep dive into React. I moved away from imperative DOM manipulation and learned to build declarative, component-based UIs.

### 🧠 Major Milestones

- **1a: Introduction to React** - Initializing projects with Vite and understanding JSX.
- **1b: JavaScript Deep Dive** - Mastering ES6 features, array methods, and arrow functions.
- **1c: Component State** - Implementing interactive UIs with event handlers and the `useState` hook.
- **1d: Complex State & Debugging** - Managing state with objects/arrays, conditional rendering, and handling immutability in React.
