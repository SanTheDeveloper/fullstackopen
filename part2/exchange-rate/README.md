# 💱 Exchange Rate API Practice

## 🎯 Objective

A standalone React application built to practice fetching and rendering data from a live third-party REST API. This project serves as an isolated sandbox for drilling the asynchronous execution loop in React.

## 🧠 Key Learnings

- **The `useEffect` Hook:** Mastered the component lifecycle by utilizing `useEffect` to trigger network requests immediately after the initial UI render.
- **Asynchronous Data Flow:** Managed the delay between the initial empty state and the resolved data state using `axios` and JavaScript Promises.
- **Controlled Inputs:** Implemented controlled React components to handle user input for currency lookups, syncing the UI with local state on every keystroke.
- **Separation of Concerns:** Maintained a clean architecture by isolating API practice away from main course projects, preventing codebase clutter.

## 🚀 Tech Stack

- React 19
- Vite
- Axios (HTTP Client)

## 🛠️ How to Run

1. `npm install`
2. `npm run dev`
